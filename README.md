# Karakoy Coffee Shop | HTML & CSS Landing Page

A mid-level frontend practice project showcasing a single-page layout for a boutique coffee shop. This project was built entirely with core HTML5 and CSS3 to master traditional page structuring techniques before moving on to modern layout modules like Flexbox or Grid.

## 🚀 Features

* **Responsive Navigation Menu:** A mobile-friendly, horizontal navigation bar that remains fixed at the top of the screen (`position: fixed`).
* **Overlay Hero Section:** A greeting area utilizing background images, `opacity` for a dark overlay, and absolute positioning to perfectly center the text.
* **Traditional CSS Layout:** Page structure divided into a sidebar and main content area using classical `float`, `clear`, and `overflow` (clearfix) techniques.
* **Detailed Table Styling:** A beautifully customized pricing table utilizing CSS combinators and pseudo-classes (e.g., `:nth-child(even)`) for a zebra-striping effect.
* **Icon Integration:** Styled footer lists using FontAwesome icons and `display: inline-block` for horizontal alignment.

## 🛠️ Built With

* **HTML5** (Semantic structuring)
* **CSS3** (Positioning, Floats, Pseudo-classes, Combinators)
* **Google Fonts** (Montserrat & Lora)
* **FontAwesome 6** (Vector icons)
